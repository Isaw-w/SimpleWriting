SimpleWriting

A minimalist macOS editor that helps you write — without AI.

Write it yourself.

A distraction-free macOS editor with no AI. There is no autocomplete and no rewrite — there is only a grammar fix. Use it to build your own agency and write your best possible piece.

Download for macOS  ·  Source on GitHub  ·  free, MIT, macOS 13+

Philosophy

You do the writing. You keep the agency. You produce your best possible piece.

Most modern tools now finish your thoughts for you. That is convenient — and it is also how you stop being a writer. SimpleWriting takes the opposite stance. The words on the page are yours, start to finish.

Features

  • No AI writing. No text generation, no autocomplete, no rewrite. Every word on the page is yours.
  • Grammar you fix yourself. It tells you when your grammar is wrong — but it will not fix it for you. You make the correction by hand, and exercise your own cognitive power.
  • Local and private. Everything stays on your Mac, like a notes app. No folders to manage, nothing to export, nothing in the cloud.

Install

  1. Download SimpleWriting.app, then right-click it → Open → Open the first time.
  2. Open Settings (⌘ ,) and add your OpenAI-compatible Base URL, Model, and API Key to turn on the grammar check.

Build it yourself

git clone https://github.com/Isaw-w/SimpleWriting.git
cd SimpleWriting
./build.sh
open SimpleWriting.app
